## 1. 岗位使命与成功结果
使命：我是 OpenClaw 与小组集群之间的一线桥梁，帮助团队快速启动、持续推进，并在共创时段结束前产出可见成果。
人数模型：定点引导共 3 人，每人覆盖 2-3 个小组。
汇报关系：我向运营/技术负责人汇报，由其分配分区、设定支持模式与处理升级。
成功标准：小组在转场后 5 分钟内启动，每个小组都产出 demo 或原型，非技术参与者也能被纳入并持续贡献。

## 2. 范围与边界
- 我负责：协助小组安装和使用 OpenClaw，建议项目方向，维持现场节奏，跟踪产出，并让非技术成员参与进来。
- 我不负责：基础设施故障处理（由 rover 负责）、流程节目决策（Program Lead 负责）、来宾接待管理（People Lead 负责）。
- 我升级给 rover 的条件：某组安装或 setup 卡住超过 5 分钟，Wi-Fi 异常，或出现我无法解决的工具 bug。
- 我升级给运营/技术负责人的条件：rover 仍无法排障，或多个小组同时卡住。

## 3. 全流程职责矩阵
| Event Phase | My Mode | What I Do |
|---|---|---|
| Setup 到 Sharing | Off-duty | 确认我自己的 OpenClaw setup 正常，并复核被分配的小组分区。 |
| Fishbowl T-10 min | Prep | 收到运营/技术负责人信号后，明显移动到我的分区并就位。 |
| Transition | Primary | 立即接管我的小组集群，协助落位，介绍 OpenClaw，推动首轮动作启动。 |
| Co-Creation | Primary | 全程引导小组，处理基础问题，维持推进节奏，并记录各组输出。 |
| Wrap-up | Support | 协助小组整理 demo 或输出用于展示，并把输出交给 Program Lead 排序。 |
| Teardown | Off-duty | 仅在被点名时提供收尾支援。 |

## 4. 个人时间线与交付物
| When | What I Need To Do | Done When |
|---|---|---|
| T-7 days | 个人完成 OpenClaw 安装与测试。 | 我可以在无人协助下演示基础功能。 |
| T-5 days | Hard gate：若尚未安装并测试 OpenClaw，将调整到非技术岗位。 | readiness 状态已被运营/技术负责人确认。 |
| T-5 to T-3 days | 参加与运营/技术负责人的 rehearsal。 | 我已演练 install path、demo path、fallback path。 |
| T-5 days | 确认我的小组分区。 | 我能在场地图上明确指出自己的分区。 |
| Day-of T-60 min | 到场并在我的分区验证 Wi-Fi 与 OpenClaw。 | 我已完成 readiness，进入可支援状态。 |
| Fishbowl T-10 min | 收到信号后移动到分区并保持可见。 | 转场时我的小组能第一时间找到我。 |

## 5. 协作对象
- 同岗引导：另 2 名定点引导覆盖相邻分区，遇到并组或单区过载时协同处理。
- Rover：流动排障角色，安装失败或 5 分钟内无法解决的 bug 直接呼叫 rover。
- 运营/技术负责人：负责分区分配、支持模式切换与 fallback 决策。
- 备份机制：若 1 名定点引导缺席，则 rover 临时补位该分区，floater 接替 roaming，由运营/技术负责人统一协调。

## 6. 升级规则
- 我自行处理：基础 OpenClaw 问题、小组鼓励、项目方向建议、非技术成员纳入。
- 我升级给 rover：安装失败、分区内 Wi-Fi 问题、5 分钟内无法排除的 bug。
- 我升级给运营/技术负责人：rover 无法解决，或我负责的小组集群同时出现多点阻塞。

## 7. 出现异常时，2 个场景
1) 小组无法安装 OpenClaw。动作：先做基础排查，重启应用与设备，复核 Wi-Fi，确认账号路径。若 5 分钟仍未恢复，立即呼叫 rover。同时把该组切到共享屏幕 demo，保持参与感和推进节奏。
2) 非技术参与者感觉被边缘化。动作：主动分配明确职责，例如创意生成、设计反馈、展示准备。现场话术要清楚，每个团队都需要思考叙事的人，不只是写代码的人。

## 8. 当日速查卡
- T-60 min：在我的分区确认 OpenClaw 可用，并检查 Wi-Fi。
- Fishbowl T-10 min：移动到我的分区并保持可见。
- Transition：接组、介绍 OpenClaw、启动首轮任务。
- Co-creation：引导团队、处理基础问题、保持节奏、确保每个人参与。
- Wrap-up：协助小组准备 demo 或输出，并交给 Program Lead。
