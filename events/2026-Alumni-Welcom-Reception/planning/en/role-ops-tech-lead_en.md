## 1. Role Mission & Success Outcomes
Mission: I own everything physical and technical, from venue setup to OpenClaw readiness to teardown, so the space works, the tools work, and every co-creation group can produce visible output.
- Venue is fully set up and handed off to all leads by T-120 min.
- All fixed guides and rover pass OpenClaw readiness by T-5 days.
- Co-creation groups launch within 5 minutes of transition.
- Degraded or fallback mode activates cleanly when needed, while preserving the event promise.

## 2. Scope, Authority, and Non-Goals
- I decide: venue layout, setup and teardown sequence, tech staffing assignments, OpenClaw support mode (normal vs guide-assisted), and rover deployment.
- I recommend: degraded or fallback mode switch (Event Lead decides), and venue change (Event Lead decides).
- I must escalate: infrastructure failure affecting multiple groups, and any fallback mode trigger, to Event Lead for final call.
- Not my job: volunteer roster (People Lead), program timing (Program Lead), check-in flow (People Lead), final event decisions (Event Lead).

## 5. Team Pods & Direct Reports
Detailed procedures stay in `plan_en.md`, this role plan defines ownership and triggers.
- Direct volunteer pods: OpenClaw Fixed Guides (3), OpenClaw Rover (1), Floor and Logistics (2-3).
- Fixed guides before event: OpenClaw installed and tested, zone assignment confirmed.
- Rover before event: install path, demo path, and fallback path fully rehearsed.
- Logistics before event: setup checklist and teardown sequence understood.
- During event: fixed guides stay in their zones, rover moves between groups, logistics handles power, seating, and signage.
- Backup trigger: if one fixed guide is absent, rover covers that zone and one floater becomes roaming support.
- Backup trigger: if rover is absent, one fixed guide goes mobile, notify Event Lead if tech pod drops below 3.

## 6. Escalation Rules
- Others escalate to me for venue and physical issues, including power, seating, signage, and temperature.
- Others escalate to me for co-creation tech issues, including install failure, Wi-Fi problems, and OpenClaw bugs.
- Others escalate to me if any group is blocked for more than 5 minutes.
- I escalate to Event Lead when infrastructure failure affects multiple groups.
- I escalate to Event Lead when fallback mode might need activation, Event Lead makes final call.
- I escalate to Event Lead for any venue safety concern.
- I notify Program Lead when tech issues can delay co-creation start or affect wrap-up timing.
## 7. If Things Go Wrong - 3 Scenarios
Scenario 1, Wi-Fi fails or is too slow for OpenClaw.
- Trigger: 3+ groups report connectivity issues.
- First 5 min: rover switches groups to hotspot or shared-demo mode, fixed guides continue offline prep.
- Notify Event Lead. Fallback: if widespread, activate degraded mode and shift to guide-assisted demos.
Scenario 2, OpenClaw installs fail for multiple attendees.
- Trigger: more than half a group cannot install.
- First 5 min: rover starts shared-screen demo, fixed guide runs collaborative walkthrough.
- Notify Event Lead for fallback consideration. Fallback: if 3+ groups are blocked, Event Lead may activate full fallback with guided ideation or mapping.
Scenario 3, venue setup is blocked by late access or missing equipment.
- Trigger: setup cannot start by T-150 min.
- First 5 min: confirm with venue partner and identify what can proceed without blocked items.
- Notify Event Lead immediately. Fallback: simplify setup, skip non-essential signage, use available furniture, prioritize power and tech zones.

## 8. Day-of Quick Card
- T-180 min: arrive first and start venue setup with logistics pod.
- T-120 min: hand off venue-ready status to all leads, then shift to tech prep.
- T-60 min: deploy fixed guides to zones, rover runs final Wi-Fi and path checks.
- T-30 min: confirm tech readiness to Event Lead during walk-through.
- Fishbowl T-10 min: receive go-signal from Program Lead, guides move to visible positions.
- Transition: ensure fixed guides receive groups, rover handles first blockers.
- Co-creation: monitor all groups, watch degraded and fallback triggers, track outputs.
- Wrap-up: collect outputs for demo showcase, then begin teardown after closing.
- Post-close: complete teardown, hand venue back clean, log issues.
