## 1. Role Mission & Success Outcomes
Mission: I am the mobile problem-solver during OpenClaw co-creation, moving across groups to unblock teams, fix setup issues, and keep momentum.
Headcount: 1 rover. Reports to: Ops/Tech Lead.
Success outcomes align with `plan_en.md` Section 9 degraded-mode response ownership.
- No group stays blocked for more than 5 minutes during co-creation.
- Degraded-mode shifts happen smoothly when needed.
- I own degraded-mode frontline response and status reporting.

## 2. Scope & Boundaries
- I do: troubleshoot install failures, fix Wi-Fi issues, move blocked groups to shared-demo mode, test all tech paths before co-creation, and keep moving between groups.
- I don't do: stay with one group for the whole session, decide fallback mode, or manage program timing.
- I escalate to Ops/Tech Lead when 3 or more groups are blocked at once, infrastructure fails beyond my control, or more hands are needed.

## 3. Lifecycle Ownership Matrix
| Event Phase | My Mode | What I Do |
|---|---|---|
| Setup | Support | Assist Ops/Tech Lead with tech zone setup. |
| T-60 min | Primary | Test Wi-Fi from all zones, verify install path, demo path, and fallback path all work. |
| Fishbowl T-10 min | Prep | Run final readiness check, confirm fallback demos are loaded. |
| Transition | Primary | Handle the first blocked group immediately, then continue mobile support. |
| Co-Creation | Primary | Roam continuously, clear blockers, shift stuck groups to shared-demo or guide-assisted mode. |
| Wrap-up | Support | Assist with output collection and quick technical cleanup. |
| Teardown | Off-duty | Assist only if asked by Ops/Tech Lead. |

## 4. Personal Timeline & Deliverables
| When | What I Need To Do | Done When |
|---|---|---|
| T-7 days | Install and test OpenClaw personally. | I can troubleshoot common install issues from direct experience. |
| T-5 days | Meet hard gate for tech role readiness. | If not installed and tested, I move to a non-tech role. |
| T-5 to T-3 days | Rehearse with Ops/Tech Lead. | Install path, demo path, fallback path, and shared-screen demo setup are all tested. |
| T-5 days | Review troubleshooting sheet from Ops/Tech Lead. | I know the top 5 common issues and fixes. |
| Day-of T-60 min | Test Wi-Fi in every zone and verify all paths. | Tech readiness is confirmed to Ops/Tech Lead. |
| Fishbowl T-10 min | Run one final readiness check. | Fallback demos are loaded and launch-ready. |

## 5. Who I Work With
- Fixed guides: 3 people in static zones. They call me when a group is stuck beyond 5 minutes, I resolve, then move on.
- Lead: Ops/Tech Lead sets support mode and fallback decisions. I report group-level status continuously.
- Backup rule: if I am absent, one fixed guide goes mobile, and one floater covers that guide zone under Ops/Tech Lead coordination.

## 6. Escalation Rules
- I handle myself: individual install failures, Wi-Fi switching, shared-demo setup, and fast troubleshooting.
- I escalate to Ops/Tech Lead: 3 or more groups blocked, infrastructure issues I cannot fix, or mode-switch recommendation needed.
- Ops/Tech Lead escalates to Event Lead for fallback mode activation, and I may brief Event Lead on current technical status.

## 7. If Things Go Wrong, 2 Scenarios
1) Widespread Wi-Fi failure. Action: shift affected groups to mobile hotspot or offline prep, then report to Ops/Tech Lead at once because this can trigger degraded mode. Priority: keep groups engaged even without connectivity.
2) OpenClaw service outage. Action: shift all groups to pre-loaded fallback demo, notify Ops/Tech Lead, and support Event Lead fallback decision flow. Priority: keep moving so every group has something actionable.

## 8. Day-of Quick Card
- T-60 min: Test Wi-Fi in all zones, verify install, demo, and fallback paths.
- Fishbowl T-10 min: Final readiness check, confirm fallback demos loaded, take mobile position.
- Transition: Handle the first blocked group immediately.
- Co-creation: Roam continuously, fix, move, fix, move. Never stay with one group for more than 10 minutes.
- If 3 or more groups are stuck: report to Ops/Tech Lead for degraded-mode decision.
- Wrap-up: Help collect outputs and close technical loose ends.
